# Slop

Internal tooling and AI-generated utilities.

## Projects

| Folder | What it is |
|--------|------------|
| [`db_meter/`](db_meter/) | NoiseWatch-7 — ambient noise monitor with dB metering, FFT spectrum analyser, and oscilloscope. Electron desktop app + Android APK. |
| [`hidrive_cctv_monitoring/`](hidrive_cctv_monitoring/) | HiDrive CCTV Review — web app for reviewing PikPak CCTV footage and logging pick accuracy events to CSV. Supports local HiDrive mount and HiDrive Online (WebDAV). Android + iOS APK available. |
| [`sensor_logger/`](sensor_logger/) | Android sensor logging app — records device sensors (accelerometer, gyro, GPS, etc.) to CSV via a Capacitor plugin. |
| [`netstr/`](netstr/) | Network Strength — authorised pentest/resilience demo tool. TUI (Textual) with live packet feed. Supports 802.11 deauth (monitor mode) and ARP spoofing/MITM with automatic ARP table restore. |
| [`predcam/`](predcam/) | PredCam — Predator-vision multi-source camera server. Web HUD with thermal/night/EM vision modes, motion detection target boxes, and animated lock-on. Phone streams camera over WebSocket; also supports USB and RTSP sources. |
