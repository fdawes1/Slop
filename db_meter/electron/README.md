# NoiseWatch-7 — Desktop (Electron)

Sci-fi HUD for real-time ambient noise monitoring. Runs in a browser or as a standalone Electron desktop app.

**Features:** dB metering · FFT spectrum analyser · oscilloscope · spectrogram waterfall · incident logging

## Run in browser

```bash
python3 -m http.server 8742
# open http://localhost:8742/noisewatch_scifi.html
```

## Run as desktop app

```bash
npm install   # first time only
npm start
```
